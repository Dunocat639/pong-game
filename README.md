# Pong Game
## Features
- 2-Players gameplay
- Score
- Velocity in function of the hit streak
- Sounds effects
- Amazing and inspiring music
- 1000 x 500 screen size
-  FPS locked at 240 FPS
- Made with C and the [raylib](https://github.com/raysan5/raylib) library

## Controls
- `W` and `S` for the left player
- `Arrow up` and `arrow down` for the right player

## Build instructions
### Linux
For now I only support Linux but in the future there will be for Windows too. Since at the momement I don't provide the game binaries you have to compile it yourself.

First you must install raylib on your system by following [these instructions](https://github.com/raysan5/raylib/wiki/Working-on-GNU-Linux) from the official raylib wiki.

Second, clone the pong-game repository and open a terminal inside it. And then just run `make run` and the game will be built and executed.
